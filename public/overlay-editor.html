어떤 오버레이를 만들까요?

목적을 먼저 선택하면 해당 타입에 맞는 설정과 기본 HTML/CSS 템플릿을 준비합니다.

기본 설정

코드 입력을 중심으로 저장하고, 기존 오버레이는 상세 API에서 코드를 복원합니다.

커스텀 신규
타입별 설정 선택한 오버레이 목적에 맞는 값을 조정합니다. HTML/CSS는 아래 코드 영역에서 계속 편집할 수 있습니다.
타입은 configJson.overlayType으로 저장됩니다.
커스텀 코드 오버레이

HTML/CSS 입력을 중심으로 제작합니다. JavaScript는 allowCustomJs 정책에 따라 sandbox에서만 실행됩니다.

빌더 설정 코드 없이 알림 위젯을 구성합니다.
표시 위젯
커스텀 HTML/CSS/JS 고급 모드 코드는 sandbox iframe 안에서만 미리보기됩니다.
등록된 알림 이미지가 없습니다.

지원 형식: PNG, JPG, WebP, GIF. 파일 크기 제한은 서버 정책을 따릅니다.

v1에서는 일반 스트리머의 JavaScript 실행을 지원하지 않습니다.
